# 마스코트 에셋 폴더

인천과학문화거점센터 공식 캐릭터 **물곰이** 이미지입니다. (사용 허가 확인 완료)

| 파일 | 포즈 | 사용되는 곳 |
|---|---|---|
| `mulgomi-idle.png` | 두 손을 든 기본 포즈, 다문 미소 | 시작 화면, 허브, 평상시 안내 |
| `mulgomi-talk.png` | 한 손을 든 놀란 표정 | 스토리 인트로, 오답 리액션 |
| `mulgomi-teach.png` | 안경 쓰고 지시봉을 든 포즈 | 개념 브리핑, 힌트, 해설 |
| `mulgomi-happy.png` | 손을 흔드는 웃는 표정 | 정답, 챕터 완료, 인증서 |

원본은 흰 배경 이미지였고, 웹에서 쓰기 위해 배경 투명화 → 여백 제거 → 높이 700px 리사이즈 →
팔레트 양자화(64색, 플랫 컬러라 육안 차이 없음) 처리를 거쳤습니다. 각 파일 약 18KB입니다.

## 교체·추가 방법

이 폴더에 `mulgomi-<mood>.png` 형식으로 넣으면 `src/components/Mascot.jsx`가 파일명으로
자동 인식합니다. 코드 수정은 필요 없습니다.

- 지원 형식: `.png`, `.svg`, `.webp` (배경 투명 권장)
- 현재 인식하는 mood: `idle`, `talk`, `teach`, `happy`
- 아쉬운 표정 에셋은 아직 없어, 오답 리액션은 `talk` 포즈 + 좌우 흔들림 애니메이션으로 대신합니다.
- 특정 mood 파일이 없으면 다른 포즈로 자동 대체되고, 파일이 하나도 없으면
  기획서 9.1절 팔레트로 그린 SVG 대체 이미지가 표시됩니다.

리액션(idle 바운스, 정답 시 점프, 오답 시 좌우 흔들림)은 CSS 애니메이션으로 처리하므로
포즈별 연속 프레임은 필요하지 않습니다.
