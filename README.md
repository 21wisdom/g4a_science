# 인천 SDGs, 사이언스 탐험대

초등 3~6학년 대상 **인천 SDGs 과학문화 리터러시 웹 게임**입니다.
「인천 SDGs 과학문화 리터러시 워크북(통합본 v2)」의 5개 파트를, 종이 위의 측정·기록 활동에서
**직접 조작하는 실험 시뮬레이션 + 판단형 퀴즈**로 옮긴 교육용 시리어스 게임입니다.

> 기획 근거: `인천 SDGs 과학문화 리터러시 웹앱 게임 기획서 v1.0`
> 마스코트: **물곰이**(인천과학문화거점센터 공식 캐릭터, 사용 허가 확인 완료)

---

## 1. 실행 방법

```bash
npm install
npm run dev      # 개발 서버 (http://localhost:5173)
npm run build    # 정적 빌드 → dist/
npm run preview  # 빌드 결과 미리보기
```

Node 18 이상이 필요합니다. 백엔드·데이터베이스·로그인은 사용하지 않습니다.

### 배포

정적 사이트이므로 Vercel / Netlify / GitHub Pages 무료 티어로 배포할 수 있습니다.
GitHub Pages처럼 하위 경로에 배포할 때는 base 경로를 지정합니다.

```bash
VITE_BASE=/g4a_science/ npm run build
```

## 2. 기술 스택

| 영역 | 사용 기술 |
|---|---|
| 프레임워크 | React 18 + Vite 5 |
| 스타일 | TailwindCSS 3 (디자인 토큰은 물곰이 팔레트 기준) |
| 차트 | Recharts (기록표 누적 그래프, 유기물 함량 비교) + 커스텀 SVG (추세선 드래그) |
| 상태관리 | Zustand |
| 저장소 | localStorage (프로필 슬롯 방식, 서버 없음) |
| 이미지 생성 | HTML5 Canvas API (프로젝트 카드 / 인증서 PNG) |
| 읽어주기 | Web Speech API (SpeechSynthesis, 한국어 — Chrome 권장) |
| 효과음 | Web Audio API로 직접 합성 (외부 음원 파일·라이선스 불필요) |
| 접속 로그 | Google Analytics 4 (`G-8XTNBN16KG`) |
| 설문 | Google Form (`https://forms.gle/CtQAkTU2ByFSzn7y8`) |

### 두 개의 공통 아키텍처

기획서 7.2·7.3의 설계를 그대로 코드로 옮겼기 때문에, 새 실험을 추가할 때는
`ExperimentShell`에 **조작 UI와 계산 함수만 갈아 끼우면** 됩니다.

```jsx
<ExperimentShell
  chapterId experimentId title intro
  controls={/* 슬라이더·버튼 */}
  visual={/* 실시간 게이지·애니메이션 */}
  columns={/* 기록표 컬럼 */}
  makeRecord={() => ({ ... })}   // 기록표 1행 생성
  chart={{ xKey, yKey }}          // 누적 기록 그래프
  interpretation={/* 해석 질문 */}
/>
```

난이도 분기는 `useGameStore(s => s.isLow())` 한 줄로 처리하며,
저학년은 이산형 버튼 + 비교/선택형, 고학년은 연속형 슬라이더 + 계산/서술형으로 갈립니다.

## 4. 챕터 구성

모든 챕터는 **스토리 인트로 → 개념 브리핑 → 실험 시뮬레이션 → 판단 퀴즈 → 토론·정리**의
5단계를 공유합니다.

| Ch | 제목 | SDGs | 미니게임 | 사용 공식 |
|---|---|---|---|---|
| 1 | 갯벌의 비밀 | 11·12·13·14 | 블루카본 실험실(건조·강열감량), 미세플라스틱 헌터(탐색·분류·순서배열) | 유기물 함량(%) = (W₂−W₃)/W₂×100 |
| 2 | 바다 탐험대 | 13·14 | 해양공간 판별 카드 소팅 + 근거 태그 | 근거 기반 분류(복수 정답 인정) |
| 3 | 데이터 탐정단 | 4 | 폭염일수 그래프 빌더, 미래예측 시뮬레이터(추세선 드래그) | 평균, 증가율(%) = (후−전)/전×100 |
| 4 | 에너지 연구소 | 7·9 | 풍력발전 시뮬레이터, 태양광 각도 실험 | 발전량 ∝ 풍속³ / 발전량 ∝ cos(입사각) |
| 5 | 우리동네 프로젝트 | 11(4·13·14·17) | 시민과학 프로젝트 빌더 4단계 위저드 | 프로젝트 기획서 양식 |

5개 챕터를 모두 마치면 **최종 통합 퀴즈 → 인증서 발급(PNG)** 으로 이어집니다.
챕터는 자유 순서로 진행할 수 있어, 교실에서 모둠별로 다른 챕터를 동시에 운영할 수 있습니다.

## 5. 데이터 원칙

게임에 등장하는 모든 수치는 `src/data/datasets.js` 한 곳에 모여 있으며,
**워크북에 제시된 값만 사용합니다.**

- 인천 갯벌 약 200㎢ / 육상 산림 대비 탄소 흡수 최대 50배
- 폭염일수: 1970년대 약 6.5일 · 2010년대 약 16.9일 · 2020년대 16.9일 이상
- 인천 인구: 2019년 약 295만 → 2025년 약 303만
- 2050년 해수면 상승 예측: 인천 4.0cm · 지구 평균 3.6cm
- 2030년 인천 해상풍력 목표: 7GW

> **선형 보간 표기**: 워크북은 인구의 2019년·2025년 두 값만 제시합니다. 꺾은선그래프의 중간
> 연도는 두 값 사이를 학습용으로 선형 보간한 값이며, 실측값(노란 점)과 보간값(흰 점)을 화면에서
> 구분해 표시하고 안내 문구도 함께 띄웁니다. 워크북에 없는 통계는 만들지 않았습니다.

블루카본 실험의 W₁·W₂·W₃는 매 시행마다 현실적인 범위 안에서 생성되는 시뮬레이션 값입니다.
지점별 유기물 함량의 **경향**(조상대 < 중간대 < 조하대)은 고정되어 있어, 반복 실험해도 같은
과학적 결론에 도달합니다.

## 6. 마스코트 에셋 교체 방법

현재는 기획서 9.1절의 실측 팔레트(몸통 `#C5DCF3` / 귀 `#F4EC8E` / 아웃라인 `#453527` /
얼굴 `#FFFFFF` / 그림자 `#BAC5CA`)와 스타일 가이드에 맞춰 그린 **SVG 대체 이미지**가 표시됩니다.

공식 에셋을 쓰려면 파일 하나만 넣으면 됩니다.

```
src/assets/mascot/물곰이외곽선-003.png   ← 여기에 복사 (배경 투명 PNG/SVG 권장)
```

`Mascot.jsx`가 이 폴더를 자동으로 감지해 SVG 대신 공식 이미지를 렌더링합니다.
코드 수정은 필요 없습니다. 리액션(idle 바운스 / 정답 시 점프 / 오답 시 흔들림)은 CSS
애니메이션으로 처리되므로 정지 포즈 1장만으로 동작합니다.

## 7. 설문·접속 로그 (기획서 17장)

- **설문**: 최종 인증서 화면 하단과 설정 화면에 Google Form 버튼을 배치했습니다.
  클릭 시 `survey_click` 이벤트를 전송해 참여율을 추정할 수 있습니다.
- **GA4**: `index.html`의 gtag 스니펫으로 연동되어 있으며, 아동 대상 서비스임을 고려해
  `allow_google_signals: false`, `allow_ad_personalization_signals: false`, IP 익명화를
  기본값으로 설정했습니다.
- **전송 이벤트**: `game_start`, `chapter_start`, `chapter_complete`(챕터·학년모드·퀴즈점수),
  `certificate_issued`, `survey_click`, `experiment_trial`(실험 재시도 횟수, 5회 단위)
- 설문 URL과 측정 ID는 `src/config.js`와 `index.html`에서 관리합니다.

**학습 데이터**: 설정 → 교사·보호자용 안내에서 `학습 기록 CSV 내려받기`를 누르면
챕터별 완료 여부·퀴즈 점수·실험 시도 횟수·자가진단 체크 수를 CSV로 저장할 수 있습니다
(개인 식별 정보 없음, 형성평가·CQI 자료용).

## 8. 아동 안전·접근성

- 이름(별명)과 학년군 외 **어떤 개인정보도 수집하지 않으며**, 모든 기록은 사용자 기기의
  localStorage에만 저장됩니다. 서버로 전송되는 개인 데이터가 없습니다.
- 아동에게 노출되는 **생성형 AI 채팅 기능은 없습니다.**
- 외부 링크(설문)는 플레이 화면이 아니라 인증서 화면과 설정 화면에만 배치했습니다.
- 모든 문항에 읽어주기(TTS) 버튼, 정답/오답을 색상만이 아니라 아이콘(⭕/❌)으로도 구분,
  터치 영역 최소 44×44px, `prefers-reduced-motion` 대응.
- 오답에 감점이 없고 재도전을 우선합니다. 점수는 "한 번에 맞힌 문항 수"로만 집계합니다.
- 경쟁 랭킹·리더보드는 두지 않았습니다.

## 9. 검수가 필요한 부분

- 퀴즈 문항과 해설, 특히 고학년 계산 문제의 **정답 허용오차**(현재 유기물 함량 ±0.5%,
  증가율 ±1%p, 평균 ±0.2일)는 실제 수업 적용 전 검토가 필요합니다.
- 배경 삽화는 저작권 확인이 필요한 원본 사진 대신 SVG 장면 카드로 대체해 두었습니다.
  AI로 재구성한 삽화를 사용할 경우 `SpaceSorting.jsx`의 `SceneCard`를 이미지로 교체하면 됩니다.
- Google Form의 실제 문항이 기획서 17.2절 초안과 일치하는지 대조 확인이 필요합니다.
